# Well-Read icon options

**B was chosen on 2026-10-13** (TSK-013). A and C are kept as alternates.

On 2026-11-11 the chosen mark was redrawn as a crisp hand-built SVG: rounded spine tops, a darker inner edge on each spine, and a page sliver on the leaning book. Charcoal `#232326` and the gold frame `#a8915f` are unchanged from the previous icon. The same artwork is used at every size; thin details (inner lines and the page sliver) recede naturally at 16 px.

| File | Option |
| --- | --- |
| `well-read-a-lectern.svg` | A: open book on a lectern (alternate) |
| `well-read-b-spines.svg` | **B: book spines on a shelf (chosen)**; source of `src/app/icon.svg`, `src/app/apple-icon.png`, `src/app/favicon.ico`, `public/icons/well-read-{192,512}.png`, and the header `LogoMark` |
| `well-read-c-monogram.svg` | C: W monogram (alternate) |
| `well-read-icons-sheet.png` | Historical comparison sheet of A, B and C at 16, 32, 64 and 180 px on light and dark (the B column shows the pre-polish mark) |
| `well-read-b-favicon-simplified.svg` | Same artwork as `well-read-b-spines.svg` (kept at this path because earlier docs and `src/app/icon.svg` pointed here). A reduced 3-spine variant is no longer needed. |

The SVGs were checked for scripts, event handlers and external references before import; none were found.
