# Security Policy

Well-Read is a personal project maintained by one person. There is no bug bounty.

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue and how to reproduce it.

Please **do not** open a public issue, pull request, or discussion for security problems.

I'll do my best to acknowledge reports promptly and fix confirmed issues, but response times aren't guaranteed.

## Supported versions

Only the current `main` branch (the live deployment) is supported.
